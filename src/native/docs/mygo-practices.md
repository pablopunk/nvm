## 1. Executive summary

1. Our `v0.7.4` pin matches the MyGo copy we can read, and MyGo already ships the palette primitives (Panel, GlobalShortcut, NewTray, NewFlyout, Secrets, Updater, Shell.InstalledApps/FileIcon, ui.Tester, the automation socket). `examples/launcher/main.go` (393 lines) is a working palette shell to copy from, with the exceptions in E13 and D2.
2. **WP2.6 premise is wrong:** MyGo's `audio` package is output-only (`docs/audio.md`, `audio/*.go`; no capture API), and `permissions.go` covers web-page camera/mic requests only. Dictation needs a native capture path (helper or purego AVFoundation). The macOS usage string (`NSMicrophoneUsageDescription`) is still mandatory (`permissions.go:30-31`).
3. **Testing is the most-used MyGo practice:** `ui.NewTester` appears 78-88 times in Godwit, cloudmusic, Kero and Lorca desktop; cloudmusic's `AGENTS.md` "Tests" section gives rules worth adopting (test only what can break; no wall clock; no label-asserting tests; pixels only for coverage; fix flaky tests, do not retry).
4. **Automation socket is ready to use for the rig:** `docs/plugins/automation.md` drives built apps by element key, input, menu, capture, eval and idle, over a 0600 Unix socket. GitHub's macOS and Windows runners already run MyGo's GUI tests (`ci.yml`), so L5 may not need a self-hosted runner for the first pass (inferred; not verified for our app).
5. **Persistence has three working references:** Godwit's `WriteFileAtomic` (temp, fsync, rename, fsync dir), its `ownerlock` flock lease, and mixmusic's hand-edit-aware store that refuses to write over a file it cannot decode. Windows needs special read/rename handling (`mixmusic/internal/store/file_other.go` comment).
6. **Agent architecture has two non-Node options that challenge D1/D2:** Godwit runs the pi agent in the pure-Go JS runtime moejs (ADR 0024) with Go keeping all HTTP, storage and approvals; mixmusic runs plugins in sobek (`go.mod`). No cloned app mentions Yaegi (every clone searched except Clipnest). WP2.4a and WP3.1 should evaluate these, not just a Node sidecar or Yaegi.
7. **Linux footprint:** `linux.webview: false` (`docs/distribution.md:545`, `docs/configuration.md:149`) makes a native-only app depend on GTK alone, not WebKitGTK. Tray needs `libayatana-appindicator3`; Wayland shortcuts need the XDG portal and an installed desktop entry (`docs/native.md:660-684`).
8. **Clipboard gaps we must own:** no MyGo clipboard change event (`clipboard.go` exports Write/Read/Formats/ReadFormat/ReadFiles/WriteFiles/Flush only), and no concealed/transient pasteboard handling in MyGo or in the ten cloned apps searched (Clipnest not searched). WP1.6 builds both.
9. **Background work pattern:** Lorca's desktop app treats a local CLI as a supervised child (readiness line, restart on exit, SIGTERM then kill after 5 s); Kero's daemon keeps sessions in `state.json` plus per-session files across restarts. Both fit WP2.4 cancellation and WP3.6 jobs better than in-process goroutines alone.
10. **Signing pitfall for any bundled native library:** cloudmusic signs its sherpa-onnx dylibs with the Developer ID so the hardened runtime loads them (`scripts/sherpa/main.go` header), and pins them by SHA-256. Any native helper or library we ship in WP2.6/WP5.1 needs the same treatment.

## 3. Findings

Each bullet: practice, evidence, why it matters for Nevermind, work packages affected.

### a) Project layout and package structure

- **A1 Feature-owned files, self-registering rows, options structs, do-nothing fakes** — mixmusic `CONTRIBUTING.md` section "Keeping changes apart": settings rows register from `init()` via `addSettings(place, order, build)`; "Options, not arguments"; fakes embed `internal/player/playertest` doubles; "Two rows at the same order stop MixMusic at start-up". Why: a palette with many providers, settings rows and shortcuts stays merge-friendly if each feature adds its own file, and fakes stay small. Affects WP1.1, WP1.11, WP0.2, WP3.10.
- **A2 Root package draws windows, services in `internal/`, one doc per part** — mixmusic `docs/architecture/README.md` (diagram: root package = pages, shell, player bar, mini player; `internal/app` = services; `internal/player` = queue) and the folder of part docs "Nothing lists them by hand". Why: matches our layer order (`platform < ... < palette < cmd`); keep `cmd/nvm` a composition root. Affects WP0.1, WP1.1.
- **A3 Thin platform backend, policy in the core** — MyGo `docs/architecture.md:154-178` ("Layers": `internal/platform` is "a small, synchronous contract"; "Keeping policy in the core is what lets `internal/fake` test almost all behavior"). Why: confirms WP0.2 ports should be intent-named and thin, with policy in our `internal/*` packages. Affects WP0.2, WP0.1.
- **A4 Main-thread rules: `Window.Update`, `RunOnMain`, `Invalidate`** — MyGo `docs/architecture.md:180-237` (every platform call on main; `onMain` runs directly when already on main, else posts and waits; `await` pumps native events on main); `loop.go:86`; `content.go:152-172`; `examples/launcher/main.go:255-269` (goroutine loads apps, then `panel.Update`). Why: same rule as our plan ("UI state only on UI thread; goroutines hand results back with `Window.Update`"). `RunOnMain` blocks, so use it only where a caller must wait. Affects WP1.1, WP0.7, WP2.1.
- **A5 Views are functions of app state; `Key` gives identity; `Handle` for persistent controls** — MyGo `docs/ui/views.md:1-60` ("Keep build values out of app state and background work"), `:150-170` (Keys: "Keys are unique among siblings"). Why: palette rows and form fields need stable identity across frames; `ui.Element` values must not outlive a build pass. Affects WP1.1, WP3.3.
- **A6 Thin native UI over a local engine process** — Lorca `ARCHITECTURE.md` "Constraints" 1 and "Three processes": the app talks only to the local CLI over localhost websocket; the CLI holds keys and runs the agent loop. Why: one option for WP2.4 (agent loop in a separate process, UI stays a client), decided in the WP2.4a spike. Affects WP2.4, WP0.1.
- **A7 Doc size budgets enforced in CI** — Lorca `ARCHITECTURE.md` (budgets: 16 KiB for the overview, 24 KiB per subject doc; `bun run check:docs`; `.github/workflows/docs.yml`). Why: our `AGENTS.md` must stay concise (CLAUDE.md rule); a checked budget keeps it so. Affects WP5.5.
- **A8 Single owner process, others via a local API with roles** — Godwit `docs/adr/0002-single-owner-local-api.md` (GUI or headless takes an exclusive lock `godwit.lock`; other processes use a local API with a 0600 token and roles `full` / `mcp`; the trust boundary is the same OS user, per the ADR's consequences). Why: our CLI or agent access to a running app should go through the owner, not the store. Affects WP0.6, WP2.1, WP3.8.
- **A9 Web content only as a view over Go-owned state** — Godwit `docs/adr/0012-native-shell-web-content.md` (the main window is native; compose, the Wit page and the message body use web views; Go is the authority for content, saves, versions, conflicts and approvals; the ADR's title says the web content is only a view). Why: the same split we want for any web-rendered piece (WP4.3). Affects WP2.3, WP4.3.
- **A10 One capability layer for native and JS plugins** — Godwit `docs/adr/0018-capability-layer.md` (capabilities declared in the manifest; one request, response and error model; an adapter per runtime; host APIs only for JS plugins). Why: our extension API (WP3.1) should keep one contract across runtimes. Affects WP3.1, WP3.2.
- **A11 Egress and send rules written as ADRs and checked in review** — Godwit `docs/adr/0003` (no extension can send), `0004` (permission gateway, title read), `0006` (at-most-once send; state machine with verify states), `AGENTS.md` "Model-facing interfaces" ("A name is a promise"; "Decide egress up front"; egress goes through an approval card that names the hosts). Why: the same questions arise for our agent tools, builder and extension capabilities. Affects WP2.4, WP3.2, WP3.8.
- **A12 Daemon owns sessions; the app is a client** — Kero `internal/daemon/store.go` header (projects and sessions in `state.json`; each session's screen and scrollback in `sessions/<id>.vt`, so the next daemon "starts every session again where it was"); `internal/service/{launchd_darwin,systemd_linux,taskschd_windows}.go`. Why: long-running agent sessions and background jobs can outlive the window. Affects WP2.4, WP3.6, WP1.10.
- **A13 Same binary runs as a background session server** — GoRex `README.md` "Persistent sessions" (`GoRex -server`; snapshot sent on attach so full-screen programs come back) and `internal/rex/server.go`. Why: a second data point for A12 on the same MyGo stack. Affects WP2.4, WP3.6.

### b) Testing, goldens and CI

- **B1 `ui.NewTester` is the default view test** — call-site counts over tracked `*.go`: Godwit 88, cloudmusic 84, Kero 79, Lorca desktop 78; mixmusic 41 plus 65 uses of the `ui.Tester` type; Lumilo 8, Godiff 5, GoRex 2, Video-Downloader 2, 2048 1, Uma 1. Why: the approach works at scale in four apps. Affects WP0.2, WP0.4, WP1.1.
- **B2 The test owns the clock; never sleep** — MyGo `docs/ui/testing.md:58-69` ("never sleep to let something happen, advance the clock"; `tt.Advance`; `tt.FramePending`); `docs/architecture.md:4469-4495` ("Waiting in tests": `internal/wait` with a one-minute guard). Why: matches our "no test sleeps" rule; gives us the `Clock` port. Affects WP0.2, WP0.5, WP1.1.
- **B3 Frame-idle budgets as tests** — cloudmusic `AGENTS.md` "Tests": "Frame budgets, in `perf_test.go`, so idle views don't start asking for frames they don't need"; caveat: `FramePending` ignores `After` frames. Why: makes "idle palette draws nothing" a regression test. Affects WP0.5, WP1.1.
- **B4 Test only what can break; visuals are not asserted by label** — cloudmusic `AGENTS.md` "Tests": under "Don't write tests that", it lists checks that a label list shows on screen, defaults, and wall-clock dependence; "Look at visuals instead of asserting on them"; "run a new UI test with -count=5. Fix or delete a flaky test; don't retry it". Why: keeps the suite honest and small; reinforces the golden rules. Affects WP0.4, WP0.1.
- **B5 Env-gated PNG dumps as visual review** — cloudmusic `internal/app/debug_shots.go` ("With `NM_SHOTS` set to a directory, the app walks through its views and saves what each window shows"); cloudmusic `AGENTS.md` (`NM_FRAMES` tests save PNGs, skip otherwise); Godiff `capture.go:1-15` (`GODIFF_CAPTURE` writes a PNG after load, then quits); mixmusic `contrast_test.go` (colour-contrast tests on theme and colour files). Why: a cheap gallery and review-sheet generator, and contrast checks for user colours. Affects WP0.4, WP0.8.
- **B6 Automation plugin drives the built app** — MyGo `docs/plugins/automation.md` (opt-in by import under a build tag; listens only when `MYGO_AUTOMATION` is set; methods `windows`, `tree`, `act`, `input`, `menu`, `capture`, `eval`, `idle`; elements by `Key`; socket mode 0600; "keep the plugin out of the builds you ship"). Why: our rig's element-level driver (instead of coordinates) is already built; WP0.3's `rigtest` should wrap it, not reimplement it. Affects WP0.3, WP0.1, WP5.1.
- **B7 MyGo's CI commands** — `.github/workflows/ci.yml`: `GOOS=darwin|linux|windows go build ./...` and `go vet`; `go vet -tags mygo_noinspector ./...`; `GOOS=js GOARCH=wasm` build and `go test -exec go_js_wasm_exec ./internal/web ./internal/gpu/gl`; `go test ./...`; `go test -tags mygo_noinspector ./ui .`; `MYGO_E2E=1 go test ./internal/e2e` (macOS and Windows runners; Linux under `xvfb-run -a dbus-run-session`); a second Linux GUI pass with `MYGO_GPU=1` on llvmpipe; natives prefetched and cached under a key of `plugins/*/mygo-plugin.json`. Why: a model for WP0.1's `native.yml`. Affects WP0.1, WP0.3, WP5.1.
- **B8 Hosted macOS and Windows runners run GUI tests** — `ci.yml`, job "Test": the non-Linux branch runs `go test ./internal/e2e` on `macos-latest` and `windows-latest`; `docs/architecture.md` "Testing" table notes on macOS, typing tests are skipped while an input method is selected. Why: L5 basics may run on hosted runners before a self-hosted Mac exists (inferred; our plan assumes it is needed). Affects WP0.3, WP1.3.
- **B9 Lumilo's CI: i18n check, race, bundle smoke** — Lumilo `.github/workflows/ci.yml` (macos-15): gofmt; `go build`; `go vet`; `go tool mygo i18n check`; `CGO_ENABLED=0 go test ./...`; `go test -race $(go list ./... | grep -v /internal/panel)`; `go tool mygo build -skip-dmg -skip-notarize -sign -`. The `-race` exclusion is explained near `lumilo/internal/panel/panel_test.go:1022` (a race found in MyGo's `internal/scene/atlas.go:157`); I did not verify the full reason. Affects WP0.1, WP5.1.
- **B10 Cross-OS vet, registry and changelog checks; an audio job with a sound server** — mixmusic `ci.yml` (jobs "Go (os)": gofmt, vet for Linux/Windows/macOS, `go test ./...`, `go run ./tools/registry -check`, `go run ./tools/changelog -check`; job "Audio output (os)": "A sound server" and "An audio device" steps). `CONTRIBUTING.md`: "Tests do not need the network" (recorded responses in `testdata/`). Why: the audio-device job is a model for the WP2.6 virtual-mic test. Affects WP0.1, WP2.6, WP5.5.
- **B11 Other shapes** — Kero `ci.yml` (`go vet`, `go test ./internal/...`, build for every platform, "Check the install scripts"; `server.yml` installs and runs a session on macOS including Rosetta); Lorca `test.yml` (cargo test per OS, `gofmt`, `go vet`, `go test`, phone-app typecheck and test), `catalog.yml`, `docs.yml`; Godwit `ci.yml` (`mise run generate`, gofmt, vet, no-cgo build, `go test -p 1`, race, `mise run build` on every platform, notarized macOS build, a check that the committed pi bundle is current). Affects WP0.1, WP5.5.
- **B12 Frame and latency numbers are kept in the repo** — MyGo `docs/ui/performance.md:8-14` (1,000 labels 397 µs/frame; visible rows of a million-row list 14.5 µs/frame; 2.5 MB retained for 1,000 labels); `docs/ui/rendering.md:23-39` (`MYGO_FRAME_STATS` logs frames over 8 ms with build/layout/paint/present and GC share); `docs/architecture.md:4592-4654` (keypress-to-screen latency on macOS: 26.6 ms average at 120 Hz); `.github/workflows/bench.yml` (every push to main, three OSes, published to a `benchmarks` branch). - **B13 Small apps have no CI** — GoRex, Godiff, 2048 and Uma have zero workflow files (tests run by hand). Why: a data point only; our plan's CI requirements are already above that bar. Affects WP0.1.

### c) Persistence and settings

- **C1 Atomic JSON store that reads before every write** — mixmusic `internal/store/store.go:1-17` (writes atomic; a file opened with `OpenWith` "may be edited by hand while the app runs"; every write reads it first; "while the file doesn't decode... writes wait until it does"); `Open()` moves an undecodable file to `path + ".broken"`. Why: user-editable files (snippets, notes, settings) need this behaviour; our plan's quarantine name (`*.corrupt-<ts>`) and no-overwrite rule are compatible. Affects WP0.6, WP1.9.
- **C2 Write-temp, fsync, rename, fsync the directory** — Godwit `core/store/files.go` (`WriteFileAtomic`: `CreateTemp` in the same directory, `Write`, `Sync`, `Close`, `Rename`, `syncDir`; `mkdirAllSync` fsyncs created parents). Why: a ready implementation of the WP0.6 atomic write; test it with a fault-injecting FS as the plan says. Affects WP0.6.
- **C3 Windows needs replace-safe read and rename** — mixmusic `internal/store/file_other.go` (`ReadFile` and `rename` have Windows variants because "a file open to read" keeps another from replacing it; elsewhere `os.Rename` is used). Why: WP0.6's Windows path needs the same split; a save while the user has the file open in an editor must not fail silently. Affects WP0.6, WP5.3.
- **C4 Single-writer lease with an exclusive lock file** — Godwit `ownerlock/lock.go:1-40` (exclusive non-blocking lock on `godwit.lock`; released on exit "however it exits"; Unix data dir must belong to the current user and is tightened to 0700; Windows relies on the user directory ACL). Why: the plan requires "a lease prevents two instances from writing the same store"; this is the implementation to copy. Affects WP0.6, WP5.3.
- **C5 Versioned state file, separate blobs for bulky data** — Kero `internal/daemon/store.go:1-30` (`savedState` with `Version`, `Projects`, `Sessions`, `Saved`; scrollback in `sessions/<id>.vt`). Why: clipboard images and session transcripts should not bloat `state.json`. Affects WP0.6, WP1.6, WP2.3.
- **C6 Versioned jobs file that drops what it cannot resume** — Lumilo `internal/core/jobstore.go:1-40` (`savedJobs` with `Version`; jobs of an engine the app no longer has are left out; "Nothing starts on its own at launch"). Why: the pattern for WP3.6 jobs and WP5.2 N-1 compatibility. Affects WP0.6, WP3.6, WP5.2.
- **C7 Conversations as SQLite rows, one per message, with backup before schema bump** — Godwit `docs/adr/0021-conversations-in-sqlite-rows.md` (sequence numbers never reused; reverting deletes rows after a sequence; `user_version` bump only after a copy of the DB; `auto_vacuum=INCREMENTAL`). Why: argues for SQLite (or at least row-level chat storage) for WP2.3 instead of whole-blob JSON. Affects WP2.3, WP0.6.
- **C8 Window geometry remembered by a key, with a pluggable store** — MyGo `docs/windows.md:87-133` (`StateKey` writes `window-state.json` on close and quit; restored only if it would show on a connected display; `App.SetWindowStateStore`). Why: the panel's remembered offset and floating notes' geometry (WP1.3, WP1.9) come for free if the key is set. Affects WP1.3, WP1.9, WP0.6.
- **C9 Secrets via the OS store, with a defined unsupported path** — MyGo `docs/native.md:496-562` (Keychain, libsecret, Credential Manager; 2,560-byte limit; `ErrSecretNotFound`; `errors.ErrUnsupported` on Linux without libsecret, with the fallback of asking for the secret each time and keeping it in memory only; `Secrets.Service(name)` to share with a CLI; macOS prompts again for a rebuilt unsigned app). Usage: lumilo (`ErrSecretNotFound` x7), mixmusic (x11), cloudmusic (`Secrets` x3). Affects WP2.2, WP3.7, WP0.6.
- **C10 App directories by convention** — MyGo `docs/app.md:229-249` (`PathUserData` = `~/.config/<Name>` on Linux, `~/Library/Application Support/<Name>` on macOS; `PathCache`; `PathLogs` = `~/Library/Logs/<Name>` on macOS; `App.SetPath` to keep test data apart). Why: our plan's `~/.config/nvm-native` is not the MyGo convention; decide whether the rewrite uses `PathUserData` (and so Electron's `nevermind` name would not collide). Affects WP0.6, WP0.7, WP5.5.
- **C11 Unfinished work is kept and shown paused** — video-downloader `internal/services/resume_store.go` (`ResumeStore` keeps non-terminal snapshots in a 0700 history directory, loaded on restart); Lumilo `jobstore.go` ("the next run shows them paused... until the user resumes or removes them"). Why: the pattern for WP1.9 drafts and WP2.6/WP3.6 interrupted work. Affects WP1.9, WP3.6, WP2.6.
- **C12 Explicit image and icon cache budgets** — mixmusic `docs/architecture/windows.md` ("Artwork"): only what shows is downloaded, scaled to its size; memory cache up to 48 MB of pixels; disk cache up to 256 MB; failed loads retry after 1-2 s and then back off to every 2 minutes; failures logged once a minute, without addresses. Why: concrete numbers for the clipboard image store (WP1.6), file thumbnails (WP1.7) and app icons (WP1.4). Affects WP1.6, WP1.7, WP1.4.
- **C13 Lazy clipboard providers and release hooks** — MyGo `docs/data-transfer.md:34-119` (`transfer.Lazy` providers run only when a paste asks; `ClipboardOptions.OnRelease`); `docs/native.md:166-190`. ### h) Pitfalls and workarounds the authors documented

- **H1 MyGo's contributor rules** — `AGENTS.md` "Hard rules": no cgo (purego and `syscall` only); purego callbacks are "a scarce, never-freed resource" (create once per signature); "Apps pay only for what they use" (measure `examples/counter-native` and `examples/hello` before and after a change); never call `reflect.Type.Method`, `Value.Method` or `MethodByName` on shared paths (linker keeps every exported method, 2.5 MB). Why: our `Bind`-style code and any reflective extension bindings (WP3.1) must follow the same rules. Affects WP0.1, WP3.1, WP5.5.
- **H2 Accelerator strings are parsed loosely but printed differently** — `internal/accelerator/accelerator.go:142-153` accepts `command`, `cmd`, `super`, `meta`, `win`, `control`, `ctrl`, `alt`, `option`, `altgr`; its output at `:40-47` prints `Super` and `Alt`. Why: our canonical storage (`Command+Alt+K`) parses correctly, but never persist MyGo's printed form; render with `shortcutLabel`. Affects WP1.11, WP0.8.
- **H3 Keys must be unique among siblings, or the tester panics** — `docs/ui/testing.md:24-26`; `docs/ui/views.md:150-166`. Affects WP0.2, WP1.1.
- **H4 Element handles are per build pass** — `docs/ui/views.md:9-20` ("Each `ui.Element` value belongs to one build pass... Stale use is diagnosed in development and `Tester`"). Affects WP1.1 (do not keep handles across frames).
- **H5 Main-thread calls before `Run`** — `docs/architecture.md:180-200` (calls that need the app panic with the call's name before `Run`; `Locale`, packaging info, login items, URL schemes and `IsOnBattery` work before `Init`). Affects WP0.7, WP1.1 (bootstrap order in `cmd/nvm`).
- **H6 Linux GPU cost and a CPU fallback** — `docs/ui/rendering.md:11-21` (Mesa adds about 50 MB the first time a native window loads OpenGL; VMs and WSL fall back to the CPU; `MYGO_GPU=0` forces the CPU renderer, `MYGO_GPU=1` forces OpenGL). ### i) Not planned, but worth a decision; risky areas to avoid

- **I1 Terminal embedding (libghostty-vt)** — MyGo `plugins/terminal` (`docs/plugins/terminal.md`, 694 lines, not read in depth; `terminal.go` 1,430 lines); used by GoRex and Kero's quick panel (`kero/quick.go`). - **I3 Notch and menu-bar overlays with raw AppKit** — mixmusic `notch_darwin.go` (purego objc; status-window level 25; tracking areas; keyboard handed back without activating). Why: a strong effect, but private-ish and fragile across macOS versions; avoid unless needed. Affects risk, not planned.
- **I4 Keep-awake** — G15. Affects not planned (WP1.10 candidate).
- **I5 Clipboard lazy transfer** — covered in C13; it is a planned WP1.6 technique but not named in the plan. Affects WP1.6.
- **I6 Sound feedback for actions** — MyGo `audio` (`docs/audio.md:1-27`: "sound an app makes itself", decoded WAV or Vorbis, mixed in Go). Why: small palette sounds on copy or paste, if wanted. Affects not planned.
- **I7 Localisation** — MyGo `docs/i18n.md` (catalogs, `mygo i18n check`, locale-aware numbers and dates); Lumilo ships 8 languages with `i18n check` in CI; Kero has `locales/`. - **I9 Automation socket for agents, not only for the rig** — `docs/plugins/automation.md` (agents drive a running app; `idle` waits for settled frames). Why: the same protocol could let an AI agent verify UI changes in the developer build; keep it out of release builds (F17). Affects WP0.3, WP2.4 (agent verification).

## 5. Open questions and things to verify on a real Mac

1. **Dictation capture path (WP2.6):** choose between the existing macOS helper (plan D4, Swift child process) and purego-based AVFoundation capture. Verify that an `NSMicrophoneUsageDescription` set in `mygo.json` is honoured by a helper child process, not only by the main bundle (inferred: the helper inherits no usage string of its own).
2. **Hosted runners for L5 (WP0.3):** run MyGo's `internal/e2e` tests and our first automation-driven test on `macos-latest` to see whether Accessibility and hotkey tests can run there or need a self-hosted Mac (B8 says the e2e job runs on hosted macOS; input-method tests are skipped there).
3. **Clipboard concealed flags (WP1.6):** test on macOS whether password-manager copies carry the `org.nspasteboard.ConcealedType` marker; none of the sources read marks it, so this is ours to confirm.
4. **Clipboard change detection (WP1.6):** measure the cost of polling `changeCount` through purego at the planned intervals; MyGo offers no change event (G10).
5. **Panel and Spaces (WP1.3):** confirm the launcher recipe (D1) keeps the previous app's menu bar and keyboard on macOS 15 and 26, on a full-screen app. MyGo's docs say so; we have not seen it run.
6. **Material and clear glass (WP1.3, WP0.8):** compare `VibrancyGlass` with `glass.Glass` on macOS 26; MyGo's docs warn that `SetActiveAppearance` is private (D12).
7. **Auto-paste and Accessibility (WP1.6, WP1.10):** check which permission prompt appears and what the Permissions view must say (D5 notes the hotkey itself needs none).
8. **Hotkey conflicts (WP1.3):** test the ordered fallback list (D4) against Raycast, Alfred and Spotlight running together.
9. **Icons off the first paint (WP1.4):** measure `Shell.FileIcon` latency per app on a 500-app machine with the icon pipeline off the main thread; the docs say it takes milliseconds per icon on the main thread (E11).
10. **Pi in moejs (WP2.4a):** run pi-ai's OpenAI and Anthropic providers in moejs against our backend's `/api/v1/chat/completions` before choosing; Godwit pins an alpha (G1).
11. **Sleep and wake (WP3.6):** test `Power.OnResume` (G14) against a real lid close during a running trigger.
12. **Linux layer shell (WP5.4):** confirm `libgtk-layer-shell.so.0` behaviour on Sway and KDE Plasma (D6); Godwit and mixmusic are not evidence for this.
13. **Native-only Linux package (WP5.4):** confirm `linux.webview: false` produces an installable package with GTK alone, and that the palette has no page to load (F9).
14. **Windows replace-safe I/O (WP5.3):** test the store's save while the file is open in Notepad or an editor (C3).
15. **Licence (all WPs):** mixmusic (GPL-3.0 or MIT), Lorca (GPL-3.0) and cloudmusic (AGPL-3.0) cannot be copied into our code without a licence decision; gorex, godiff, 2048 and uma have no licence file. Only patterns are used in this note. Decide before any code is lifted.
16. **Pulse and MyTwig (showcase):** Pulse has no public repo that I could find, and MyTwig's source is not public. Neither was read.
17. **Clipnest (WP1.6):** README-only, per the brief. Its README says it excludes apps, asks for an Accessibility permission for auto-paste, and keeps 50 summaries per page. Verify those claims, and its clipboard-privacy handling, from its code before relying on them.
18. **Not read in depth:** `examples/gallery`, `examples/notes`, `examples/vibrancy`, `examples/menubar-flyout`, `examples/mayoi`, `plugins/terminal` and MyGo's `docs/native.md` Network and Watching files sections. These are the next reads for WP0.8, WP1.9, WP1.3, WP3.5 and WP1.7.
