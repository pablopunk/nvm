Visual values are capture intervals: the lower bound is the start of the last capture before the final stable state, the upper bound the end of its first capture, both measured from key dispatch start. The end of an action is the first frame after the last list change, held at least 1 s. They bound observed content, not exact application execution or display scanout. Calculator: expression already entered, unique clipboard sentinel verified before Enter, result varies per attempt; includes key injection and clipboard polling. p95 is nearest rank. No observer overhead was subtracted.
Linux: 4 CPU / 4 GiB Debian LXC on a shared host; Xvfb 1280×800, Openbox, software rendering. Alternating AB/BA blocks, isolated offline profiles with identical 51,000-file fixtures (default indexing limits differ), one 60-second priming launch per profile. Snapshots sum current descendants about every 100 ms; short-lived or reparented processes can be missed. Observer and shared-host load were not subtracted.
